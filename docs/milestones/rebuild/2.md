## 2. Do not add VectorBT in PR 1

The currently selected VectorBT package uses Apache 2.0 with the Commons Clause.

That does not satisfy a strict “OSI-approved open-source libraries only” requirement without an explicit owner-approved exception.

Therefore:

```text
do not add vectorbt to pyproject.toml
do not raise the Python floor solely for vectorbt
do not create a populated research extra yet
```

Update `DECISIONS.md` to record:

```text
VectorBT status: BLOCKED_PENDING_LICENSE_DECISION
```

Explain:

- it is source-available/fair-code rather than conventional OSI-approved open source;
- internal use may be permitted by its terms, but commercial or hosted use requires separate review;
- this repository has not yet approved an exception;
- PR 5 must evaluate an OSI-approved alternative or obtain explicit owner approval before adding VectorBT.

Reframe the future PR 5 title from:

```text
VectorBT research adapter
```

to:

```text
Vectorized research library selection and adapter
```

PR 5 may select VectorBT only after the license decision is explicitly approved and recorded.

Do not make a legal conclusion. Record the licensing classification and project decision only.
