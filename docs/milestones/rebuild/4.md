## Implementation

Use the `XNYS` calendar from `exchange_calendars` as the sole authority for U.S. equity sessions.

Preserve the existing public function names and signatures unless caller analysis proves a signature can safely change.

Replace all hand-written holiday calculations and fixed-session assumptions in `market_calendar.py`.

Required semantics:

* `is_weekend(day)` remains a simple calendar-weekend check.
* `is_trading_day(day)` uses XNYS session membership.
* `is_market_holiday(day)` returns true for a non-weekend weekday on which XNYS has no session, including one-off exchange closures.
* `next_trading_session(day, inclusive=False)` preserves strict/inclusive behavior.
* `add_trading_days(start, n)` preserves:

  * `n < 0` raises `ValueError`;
  * `n == 0` returns `start`;
  * `start` is day zero;
  * positive values count subsequent XNYS sessions.
* `is_market_open(moment)`:

  * requires a timezone-aware datetime;
  * uses the actual XNYS session schedule;
  * returns false before open, after close, on weekends and holidays;
  * correctly handles DST and early-close sessions;
  * does not treat pre-market or after-hours as open.
* `regular_session_close(day)` returns the actual scheduled close, including early closes, as a timezone-aware `America/New_York` datetime.
* Preserve fail-closed `MarketCalendarError` behavior when inputs or calendar resolution are invalid.

Do not retain:

```text
_nth_weekday_of_month
_last_weekday_of_month
_easter_sunday
_observed
_federal_holidays
fixed 16:00 close assumptions
custom holiday fallback logic
```

Do not add a custom fallback if `exchange_calendars` fails. Raise `MarketCalendarError`.

Cache the XNYS calendar object safely so it is not reconstructed on every call.
